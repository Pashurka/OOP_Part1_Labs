# Лабораторні роботи з дисципліни «Об'єктно-орієнтоване програмування», частина 1

Репозиторій містить приклади виконання лабораторних робіт з дисципліни **«Об'єктно-орієнтоване програмування»**, виконані мовою програмування **C#** у середовищі **Microsoft Visual Studio 2026**.

## Мета курсу

Опанування основних принципів об'єктно-орієнтованого програмування, набуття практичних навичок проєктування класів та ієрархій класів, використання механізмів успадкування, поліморфізму, абстракції, інкапсуляції та інших можливостей мови C#.

## Перелік лабораторних робіт

### Лабораторна робота №1. Знайомство з середовищем Visual Studio та вимогами до оформлення коду
Ознайомлення із середовищем розробки Visual Studio, основними вимогами до оформлення коду C#. Створення та налагодження програми з використанням змінних, констант, масивів, циклів, умов і методів.

### Лабораторна робота №2. Класи, об'єкти, поля, властивості, модифікатори доступу
Створення базового класу відповідно до предметної області. Оголошення приватних полів, реалізація властивостей для доступу до них та створення екземплярів класу.

### Лабораторна робота №3. Елементи даних та функціональні елементи класів
Доповнення класів методами, використання модифікаторів доступу та перевантаження методів. Демонстрація роботи об'єктів і методів.

### Лабораторна робота №4. Дослідження технологій побудови UML-діаграм класів
Створення UML-діаграми класу графічним засобом Draw.io та за допомогою мови PlantUML. Порівняння технологій побудови діаграм.

### Лабораторна робота №5. Конструктори та деструктори класів
Реалізація конструкторів за замовчуванням, з параметрами та копіювання. Дослідження особливостей створення і знищення об'єктів.

### Лабораторна робота №6. Наслідування класів
Створення ієрархії класів із базовим та похідними класами. Використання успадкування, віртуальних і перевизначених методів.

### Лабораторна робота №7. Приховування полів, властивостей та методів у похідному класі
Дослідження механізму приховування елементів базового класу за допомогою ключового слова `new`. Використання ключового слова `base`.

### Лабораторна робота №8. Поліморфізм. Віртуальні методи та їх перевизначення
Реалізація поліморфізму за допомогою `virtual` та `override`. Дослідження модифікаторів доступу класів і їхніх елементів.

### Лабораторна робота №9. Абстрактні класи та абстрактні елементи класу. Запечатані та статичні класи
Створення абстрактного класу та класу-спадкоємця. Реалізація абстрактних елементів, використання `sealed` і статичних класів.

### Лабораторна робота №10. Робота з файловою структурою C#-проєкту
Реструктуризація проєкту шляхом розміщення класів в окремих файлах. Організація просторів імен та структури проєкту.

### Лабораторна робота №11. Перевизначення стандартних операторів в класах
Перевантаження операторів `true`, `false`, `&`, `!`, `+` та `--`. Демонстрація використання перевизначених операторів.

### Лабораторна робота №12. Графічний інтерфейс користувача Windows Forms
Розробка застосунку Windows Forms для створення, додавання, видалення та відображення об'єктів у колекції з використанням `DataGridView`.

### Лабораторна робота №13. Графічний інтерфейс користувача Windows Presentation Foundation
Розробка застосунку WPF для роботи з колекцією об'єктів: додавання, видалення та відображення записів засобами графічного інтерфейсу.

### Лабораторна робота №14. Розробка складних класів
Створення ієрархії класів із двома базовими та чотирма похідними класами. Використання конструкторів, успадкування, поліморфізму, перевизначення та приховування елементів класів.

### Лабораторна робота №15. Розробка складних ієрархій класів
Створення складної ієрархії класів із використанням абстрактних, звичайних, запечатаних і статичних класів. Реалізація успадкування, поліморфізму, перевизначення методів та операторів.

## Використані технології

- **Мова програмування:** C#
- **Середовище розробки:** Microsoft Visual Studio
- **Платформа:** .NET
- **Моделювання:** UML, PlantUML
- **Графічні інтерфейси:** Windows Forms, Windows Presentation Foundation (WPF)

## Основні теми курсу

У межах лабораторних робіт розглядаються:

- класи, об'єкти, поля та властивості;
- модифікатори доступу та інкапсуляція;
- методи та їх перевантаження;
- конструктори та деструктори;
- успадкування та ієрархії класів;
- поліморфізм, віртуальні методи та їх перевизначення;
- приховування елементів класів;
- абстрактні та запечатані класи;
- статичні класи та члени класів;
- перевантаження операторів;
- організація файлової структури проєктів;
- колекції та графічні інтерфейси користувача;
- UML-моделювання класів.
